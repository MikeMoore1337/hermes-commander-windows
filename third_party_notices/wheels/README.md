# Python wheel notices

The files in wheel-named directories are unchanged copies of license files
from the eight wheel archives listed in `wheels.json`. Their SHA-256 hashes
were recorded from the isolated Windows build for PR #2. The corresponding
third-party license terms remain in force; the repository's first-party MIT
license does not replace them.

These build-tool and dependency notices are not a complete list for the
compiled installer. Python, OpenSSL, .NET and native DLLs require their own
review and notices. No binary installer is distributed by this repository.
